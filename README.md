# Web nanečisto — [Vaše jméno], osobní trenérka

Tento balíček obsahuje kompletní, hotový web (HTML/CSS) podle zadání:
- index.html — hlavní stránka, O mně, metodika, fotogalerie, blog přehled, kontakt
- clanek-1-mobilita.html, clanek-2-izometrie.html, clanek-3-silovy-trenink.html — tři články o vaší metodice
- style.css — vzhled webu (tmavé pozadí, červeno-růžové akcenty podle stylu vašich fotek)

## Co je potřeba doplnit

1. **Fotky** — do složky "images" nahrajte své fotky přesně pod těmito názvy (aby se automaticky zobrazily):
   - foto-trenink-1.jpg, foto-trenink-2.jpg, foto-trenink-3.jpg
   - foto-zavod-1.jpg, foto-zavod-2.jpg, foto-zavod-3.jpg, foto-zavod-4.jpg
   - certifikat-1.jpg (a případně další certifikáty — přidejte i do gallery-grid v index.html)
2. **Jméno** — v souborech nahraďte "[Vaše jméno]" svým jménem (v index.html i v obou článcích, hlavička a patička).
3. **Kontakt** — v sekci Kontakt v index.html nahraďte "[váš-email@example.com]" a "[+420000000000]" svými skutečnými údaji, případně přidejte odkaz na Instagram/Facebook.

Jak nahrát fotky přímo na GitHubu: otevřete repozitář, přejděte do složky images, klikněte na "Add file" → "Upload files" a přetáhněte fotky pod uvedenými názvy.

## Živý web

Web běží na GitHub Pages (zdarma) na adrese uvedené v nastavení repozitáře — Settings → Pages.
